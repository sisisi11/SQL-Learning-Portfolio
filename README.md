# SQL Learning Portfolio

A structured SQL Server self-study portfolio, starting with basic querying and progressing toward analytical SQL, database programming and a final Fraud & Transaction Risk Analytics project.

The exercises use synthetic data and are organized so that each stage builds on concepts introduced earlier.

## Learning path

### 1 — Query Fundamentals

SELECT, aliases, DISTINCT, WHERE, ORDER BY, TOP, expressions, string/date functions, CASE and NULL handling.

### 2 — Aggregation \& Grouped Analysis

COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING and conditional aggregation.

### 3 — Relational Queries

INNER JOIN, LEFT JOIN, multi-table joins and revenue/customer analysis.

### 4 — Subqueries, CTEs \& Window Functions

Scalar/correlated subqueries, EXISTS, CTEs, ROW\_NUMBER, RANK, LAG, LEAD and running totals.

### 5 — Reusable SQL \& Performance

Views, stored procedures, functions, indexes, data-quality checks and query-oriented design.

### Final Project

Fraud Detection \& Transaction Risk Analytics using Microsoft SQL Server / T-SQL.

All data is synthetic and used for learning and portfolio demonstration.
